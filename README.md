# ai-foundations-weekly-audio

Audio hosting only, for the "Full Week" episodes of the AI Foundations podcast
(feed and code live in bel9777/ai-foundations-daily-audio, `weekly.py`).
Served by GitHub Pages so files go out as audio/mpeg. GitHub Release assets
were tried first (2026-10-05) and podcast apps refused them: they are served as
application/octet-stream behind an expiring redirect.

Written only by weekly.py. Do not edit by hand.
